# Noor — Islamic Amal

A Bengali-first Quranic amal and ruqyah reference website built with React + TypeScript + Vite.

## Run locally
1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal in this folder and run:
   `npm install`
   `npm run dev`
4. Open the local URL shown by Vite.

## Deploy
Push the project to a GitHub repository, then import that repository in Vercel.
Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

## Content accuracy notice
The current entries are a UI/content-structure prototype. Arabic text, transliteration, and Bengali meaning must be checked against a trusted Mushaf and translation before public release. The `verified` flag is intentionally false. Do not present any entry as a guaranteed cure or prescribe unsupported counts/timings.
